# Лабораторная работа №2. Коллекции и компараторы в Java

**Автор:** Теплякова Анастасия Владимировна
**Группа:** ФИТ-251

## Что реализовано

- **Задание 1** — методы `Collections`: сортировка, перемешивание, циклический сдвиг, уникальные, дубликаты, частоты через `HashMap`.
- **Задание 2** — генератор простых чисел `PrimesGenerator` с перебором через `Iterator`, вывод в прямом и обратном порядке.
- **Задание 3** — класс `Human` с `Comparable`, компаратор `HumanComparatorByLastName`, сравнение `HashSet` / `LinkedHashSet` / `TreeSet`.
- **Задание 4** — частота слов в тексте через `HashMap` без учёта регистра.
- **Задание 5** — обмен ключей и значений в `Map<K, V>` через обобщённый метод.

## Как запустить

1. Открой проект в IDE (OpenIDE / IntelliJ IDEA).
2. Запусти `src/ru/university/laba3/Main.java` — откроется меню выбора заданий.
3. Выбери номер задания от 1 до 5 или `0` для выхода.
